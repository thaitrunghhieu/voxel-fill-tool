# 3D Voxel Fill Tool

Browser-based Three.js voxel filling tool inspired by uuuulala/Threejs-voxel-art-tutorial.

## Use
Open the GitHub Pages URL, import a GLB/GLTF/OBJ/STL model, choose voxel size and Solid Fill, then click VOXELIZE.

Solid Fill works best with closed / watertight meshes.
